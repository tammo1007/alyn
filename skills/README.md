# Alyn skills

Skills that make any agent better at finding, using and writing skills.

| Skill | Use it when |
| --- | --- |
| [find-skill](find-skill/SKILL.md) | A task could use a specialized skill and the agent should look before improvising. |
| [skill-check](skill-check/SKILL.md) | You write or publish a skill and want it to score well on the Alyn Score. |
| [alyn-setup](alyn-setup/SKILL.md) | You want a complete skill stack for one kind of work in one step. |

Install all three:

```bash
npx skills add tammo1007/alyn
```

Or one of them:

```bash
npx skills add tammo1007/alyn --skill skill-check
```

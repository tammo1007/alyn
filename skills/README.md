# Alyn skills

Skills that make any agent better at finding and using skills.

| Skill | Use it when |
| --- | --- |
| [find-skill](find-skill/SKILL.md) | A task could use a specialized skill and the agent should look before improvising. |
| [alyn-setup](alyn-setup/SKILL.md) | You want a complete skill stack for one kind of work in one step. |

Install both:

```bash
npx skills add tammo1007/alyn
```

Or one of them:

```bash
npx skills add tammo1007/alyn --skill find-skill
```
